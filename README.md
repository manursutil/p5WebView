# p5 WebView Popout

Opens the current p5.js sketch in a VS Code webview — either in a separate floating window or a split view.

## Commands

- **p5: Open Sketch in Separate Window** — pops the sketch into its own floating window (VS Code ≥ 1.85)
- **p5: Open Sketch in Split** — opens the sketch beside your code

## Usage

Open a `.js` sketch file, then run a command from the Command Palette (`Cmd+Shift+P`) or the editor title run menu. Requires an internet connection (p5 is loaded from CDN).
